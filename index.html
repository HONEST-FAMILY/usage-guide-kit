01

기본

Ant Design 기본 예제와 같은 구성입니다. 첫 장에 그림을 넣고, 아래 점으로 진행을 보여 주고, 이전·다음으로 넘깁니다.

02

화면을 막지 않는 모드

어둡게 깔지 않고 강조색 말풍선만 띄웁니다. 이미 쓰던 사람에게 새 기능만 알릴 때 씁니다. 말풍선이 떠 있어도 화면을 그대로 누를 수 있습니다.

03

위치 지정

말풍선을 위·아래·왼쪽·오른쪽에 둘 수 있습니다. 자리가 모자라면 스스로 반대편으로 옮기고, 화면 끝에 닿으면 안쪽으로 밀어 넣습니다.

04

몇 번째 단계인지 점, 숫자, 막대 중 하나로 보여 줍니다. 기본은 점이고, 지나온 단계는 옅은 색으로 남겨 어디까지 왔는지 보이게 했습니다.

05

실제 관리자 화면에서

고객사 '상품 등록' 화면을 흉내 낸 예시입니다. 들어오자마자 덮치지 않고, 카테고리 옆 깜빡이는 점이나 오른쪽 위 '사용 가이드'로 시작합니다. 투어는 3단계만, 나머지는 칸 위 한 줄 설명이 맡습니다. 한 번 끝내면 점이 사라지고, '사용 가이드'로 언제든 다시 봅니다.

06

Ant Design 투어에서 가져온 것, 우리가 더한 것

코드는 한 줄도 가져오지 않았습니다. 화면 구성과 움직임만 보고 처음부터 새로 짰습니다.

가져온 것

  • 첫 장에 그림을 넣는 구성
  • 아래 점으로 보여 주는 진행 표시
  • 이전·다음·닫기 단추 배치
  • 화면을 막지 않는 모드와 강조색 말풍선
  • 위·아래·왼쪽·오른쪽 위치 지정
  • 강조 영역 여백·둥글기 조절

우리가 더한 것

  • 폰에서는 화면 아래 시트로 바뀝니다. 설명창이 잘리지 않습니다. (Ant Design 문서 예제를 폰 폭 390px로 열었을 때는 설명창 왼쪽이 잘렸습니다 — 10/16 실측)
  • 강조 테두리가 대상에 딱 맞습니다. 스크롤바가 있는 윈도우 PC에서도, 화면이 나중에 밀려도 따라갑니다.
  • 대상이 화면 밖이면 부드럽게 데려옵니다. 스크롤 상자 안에 있는 칸도 찾아갑니다.
  • 설명창이 화면 끝에 닿으면 반대편으로 옮깁니다. 그래도 넘치면 화면 안으로 밀어 넣습니다.
  • 사용자가 시작합니다. '사용 가이드' 단추나 깜빡이는 점으로 열고, 끝내거나 닫은 사람에겐 다시 뜨지 않습니다.
  • 키보드 ← → Esc로 넘기고, 화면 낭독기에 "3단계 중 2단계"를 읽어 줍니다.
  • 움직임 줄이기를 켠 사람에겐 움직임을 끕니다.
  • 리액트가 아니어도 됩니다. 뷰·라라벨·일반 HTML 어디든 파일 두 개면 됩니다.
  • 한국어 문구가 기본이고, 고객사 색으로 한 줄이면 바뀝니다.

실측: PC 1440×900·1920×1080(윈도우 스크롤바 포함), 태블릿 768×1024, 폰 390×844에서 이 페이지의 모든 투어 100단계 — 설명창이 화면 밖으로 나가거나 강조 테두리가 대상에서 어긋난 경우 0건.
